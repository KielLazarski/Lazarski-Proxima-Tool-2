# Frozen prospective predictions

Recorded 2026-10-28, before the readouts. These are the only honest test of the
bench: the calibration set was edited during tuning, so its 97% is a fitted
number. These are not.

Do not edit this file after a readout. Record outcomes in a separate section.

## P1 — KT-621 (STAT6) BROADEN2 Phase 2b, due by year-end 2026

**Bench verdict: TOP** (composite 56.4, validity 50.7, modality 62.8)

The bench says degradation is the right tool and the target is real. It reaches
that without any Phase 2 data: validity comes from dupilumab on the axis plus
Phase 1b biomarkers, modality from an intracellular TF with no tractable
inhibitor, good degron features and slow resynthesis.

**Prediction:** BROADEN2 hits its primary endpoint with a placebo-adjusted EASI
effect materially above the dupilumab-era bar for an oral.

**What falsifies the bench, not just the drug:** a clean miss on efficacy with
confirmed skin STAT6 degradation above 90%. That would mean degrading a
validated intracellular node does not reproduce blockade of the axis — which is
the platform's core assumption, not a fact about one molecule.

## P2 — Lp(a)HORIZON full data, AHA 7 November 2026

**Bench verdict: REJECT_WRONG_MODALITY** — secreted, so out of scope for a TPD
bench regardless of the validity debate.

This one tests the *validity* layer in isolation, not the bench's output.

**Prediction:** subgroup data show a larger effect at higher baseline Lp(a),
consistent with the absolute-reduction model rather than target refutation. If
instead the effect is flat across baseline strata, the MR-implied dose-response
model is wrong and the `mr_unmatched_discount` term needs to be harsher than
0.60 across the board.

## P3 — ZEUS full data, AHA 7 November 2026

**Bench verdict on IL6R: REJECT_TARGET_INVALID** (validity 0 after the trial).

The bench only gets this right *retrospectively*. Scored on pre-ZEUS evidence,
IL6R had replicated protective LOF genetics and MR support, and would have
scored well.

**This is the bench's known blind spot.** The honest statement is that no
configuration of the current validity layer would have rejected IL6R before
July 2026.

**Prediction:** the full data show target engagement was achieved and the null
is not explained by dosing. If a subgroup effect appears in lower-CKD or
lower-HbA1c patients, then population context belongs in the validity model as
an explicit term, and that is a concrete change to make.

## P4 — Kymera Q3, 29 October 2026, and KT-579 (IRF5) Phase 1

**Bench verdict on IRF5: NOMINATE_FOR_VALIDATION** (validity 17.0, modality 61.2)

The bench says the modality case is strong and the validity case is not yet
made. That is a testable claim about what should happen next: a perturbation
experiment in disease-relevant primary cells, not more mining.

**Prediction:** KT-579 Phase 1 reports clean safety and target degradation
without efficacy data, leaving validity exactly where the bench put it.
